# Dailer X brand assets

- `dailerx-mark.svg`: scalable vector source for the original Dailer X mark.
- `dailerx-mark.png`: 512px PNG app/social icon export.
- `charcoal-gold-background.png`: optional sample wallpaper; the app also lets each user choose an image from their device.

The Android interface uses Material vector icons (AndroidX Compose Material Icons) and a native VectorDrawable app mark. No emoji are used as interface icons.
